# Security Policy

## Reporting a Vulnerability

We take the security of our systems seriously, and we value the security community. If you believe you have found a security vulnerability in our project, we encourage you to notify us promptly.

Please refrain from publicly disclosing the submission in order to preserve our users' security.

1. Contact us via the email address in our GitHub profile.
2. Provide a clear description of the vulnerability, including steps to reproduce it.
3. Include any POC (Proof of Concept) or references that might help us resolve the issue quickly.

## Security Best Practices

- Regularly update dependencies in `requirements.txt`.
- Use HTTPS for all API interactions.
- Regularly perform security audits on code.
- Keep the `.env` file secret and never expose sensitive data in version control.
